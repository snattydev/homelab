## 🌐 Network-Based Experiments

### 🧠 Ubuntu Linux Server
I started learning about this with my old laptop that had an amazing first gen intel i3-M370 and 3 gigs of RAM. The cherry on top is that it has *no battery* (why are replacement parts so expensive...)

Even though the setup was kind of scuffed, I was able to explore:
- Installing and configuring **Ubuntu Server**
- Getting to know the basics of **Docker**,  **SSH**, **Linux Terminal Usage**

💡 *It was a great introduction to server concepts, resource management, and CLI-based administration.*

---

### 📡 OpenWRT
My motivation to optimize my home network made me land into custom router firmware.
Flashing **OpenWRT** onto a **TP-Link Archer C20 V5 <W>** was rather an interesting thing to do when i did NOT have a backup router (funny enough, this C20 V5 <W> does NOT exist as a real model, but thanks to some random community forum, i found out it is a V4 model but sold by ISPs).

What I've Learned:
- Researching compatibility and firmware builds
- Flashing routers without bricking them (scary!)
- Configuring my network setup efficiently

🔧 *This was my first experience with a truly open-source router environment — learning about DHCP, DNS, INTERFACES and more.*
